# Character artwork provenance

The v2/v3 reference images were generated with OpenAI image generation for Cloudsong from its original icon and
character direction. Prompts are preserved in each version's README. They are project artwork, not extracted
assets from Sky or another game.

The v3 original mesh, PBR textures and rig were generated in the user's Hyper3D account with Rodin, using these
references. The user approved the upload and requested game integration. Source and rig generation IDs and the
permanent result links are recorded in `character-v3/README.md`. The original downloaded export is preserved;
`character-v3/prepared/hero.glb` is a derivative prepared by `tools/prepare_hero.py`.
