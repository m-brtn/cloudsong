# Credits

Cloudsong's isles, grass, flowers, ruins, figures, textures, light effects, music and its own sounds are generated by
its own code (`src/`, `shaders/`) at build or run time. The app icon is AI-generated project artwork. External resources and artwork provenance are listed below.

| File | What | Source | Licence |
| --- | --- | --- | --- |
| `icon/cloudsong-daylight.png` | App icon | OpenAI built-in image generation, 2026-11-08; prompt in `icon/README.md`, no third-party input images | AI-generated project artwork, created for use in Cloudsong |
| `assets/fonts/Marcellus-Regular.ttf` | Marcellus, the titles' font, unmodified | Google Fonts (`github.com/google/fonts`, `ofl/marcellus`, SHA-256 `1cf0cd10b17d35e852729962cc1ffaffed94514895972458345e2df34abb2f81`) | SIL Open Font License 1.1, copyright 2012 Brian J. Bonislawsky DBA Astigmatic (AOETI), Reserved Font Name "Marcellus"; the licence text is `assets/fonts/OFL.txt`, shipped next to the font |
| `quench/weather/wind_light.wav`, `wind_strong.wav` (cooked at build time) | the wind | the engine's procedural weather sounds (`quench_weather_sounds()`, its `tools/assets/make_weather_sounds.py`) | MIT, as the engine |

The engine, [Quench](https://github.com/m-brtn/Quench), is MIT licensed; the libraries it ships and their licences
are listed in its `THIRD_PARTY_LICENSES`, which a package of the game carries next to the app.
