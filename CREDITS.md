# Credits

Cloudsong contains no third-party art, music or sound files. Its isles, grass, flowers, ruins, figures, textures,
light effects, music and sounds are generated by its own code (`src/`, `shaders/`) at build or run time.

The engine, [Quench](https://github.com/m-brtn/Quench), is MIT licensed; the libraries it ships and their licences
are listed in its `THIRD_PARTY_LICENSES`, which a package of the game carries next to the app.
